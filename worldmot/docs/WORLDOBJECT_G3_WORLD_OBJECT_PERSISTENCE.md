# World Object G3 — TEST persistence and identity

The causal persistent bank is evaluated separately from an oracle association
diagnostic. Across 332,781 identity observations, the predicted bank produces
85,155 identity switches and 31,958 wrong world-object merges. The oracle
diagnostic has zero switches by construction; it is included only to separate
formation/support errors from persistence errors.

The detailed failures are in `G3_temporal_identity_failures.json` and the
compact route summary is `G3_oracle_vs_predicted_all24.csv` (the filename is
retained for compatibility; its `split` field is TEST and contains all 22
TEST scenes).
