# WorldMOT v1/v2 全场景筛查与 GMT 对照

生成日期：2026-10-22。该报告记录真实运行结果，不把筛查结果写成正式 MOT 结论。

## 测试范围

- v1：24 个场景，每个场景前 100 个同步双摄时刻，共 2,400 个时刻；RTMDet-Ins-tiny、已核验 VGGT-Ω 512 原版权重、3D fusion、WorldIdentityMemory。
- v2：24 个场景，每个场景前 20 个同步双摄时刻，共 480 个时刻；使用只在 Scene 8 前三帧训练的 pilot checkpoint，`formal_inference_allowed=false`，因此只作诊断。
- GMT：读取 p2 development guard 的原始官方结果。原始 GT 合法且完成的只有场景 1、10、11、18、19；场景 2、3、14、15、16、22、23 被重复键审计阻断。

## 逐场景结论

- v1：24/24 场景成功写出 100 条记录；场景间 HOTA 从 24.65% 到 88.14%，拥挤场景 15、23、24 的 IDSW 分别为 1,045、762、462。
- v2：24/24 场景数据流成功，但 7,685/7,685 观测均未分配，0 birth；pilot query 没有形成可评测轨迹。因此没有 v2 的 HOTA/IDF1，也没有“比 v1 提升”的证据。
- 速度：v1 端到端同步时刻平均 1.674 s（P50 1.505 s，P95 2.908 s，0.598 FPS）；v2 平均 1.843 s（P50 1.670 s，P95 3.076 s，0.543 FPS）。GMT 的 6.037 FPS 使用其官方完整视频计时口径，不能直接视为同一实现的延迟。
