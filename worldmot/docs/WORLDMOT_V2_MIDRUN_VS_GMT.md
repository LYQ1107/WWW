# WorldMOT v2 中途诊断：v2 与 GMT

状态：诊断评测已完成，但不是最终全方法官方比较。

## 评测范围

使用同一 `evaluate_fullvideo.py`、同一 `tracks_2d_by_camera` 输出协议和同一原始 GT。只有已经完整覆盖 22 个 TEST 场景的方法进入本次比较：`v2_joint_seed20261022`、`v2_joint_seed20261023` 和 `gmt_native`。TrackEval 实际只接受 14 个 GT 合法场景；场景 5、12、13、14、17、20、21、22 因原始 GT 重复/版本审计不合法而阻断，未修改 GT、未制造分数。

`v2_joint_seed20261024` 仍缺少完整 Scene 22，所有已登记消融也仍在独立 TEST 中，因此不计入本表。

|---|---:|---:|---:|---:|---:|---:|---:|
| v2 seed 20261022 | 36.476 | 44.736 | 30.250 | 43.365 | 36.299 | 875 | 1347 |
| v2 seed 20261023 | 37.527 | 46.850 | 30.612 | 45.344 | 36.757 | 1057 | 1441 |

| GMT native | 66.065 | 69.579 | 63.066 | 80.112 | 72.964 | 6044 | 1584 |

## 当前解释

在这 14 个合法场景上，v2 两种子均值暂时低于 GMT：HOTA `-29.063`、AssA `-23.786`、DetA `-32.635`、IDF1 `-35.758`、MOTA `-36.435` 个百分点。v2 的 IDSW 少 `5078`，但这是在明显较低的检测/跟踪覆盖下取得的，不能解释为整体身份关联优于 GMT；其 FN 反而多 `89466.5`。

因此当前结论只能是：**已完成主 v2 种子暂未显示相对 GMT 的总体收益**。这不是最终结论，因为第三个主种子、消融方法和剩余完整 TEST 尚未结束；最终报告仍须使用全注册方法的同协议结果。
