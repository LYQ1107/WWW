# World Object TRAIN preflight (Scenes 1–8)

This is an early engineering preflight over the eight complete scenes available while the six-GPU TRAIN Ω cache is still running. It is not the formal all-24 TRAIN result and it does not select TEST parameters.

## Scope

- Cache: frozen GMT detector observations + VGGT-Ω 512 sparse support.
- Frames: 8,255 synchronized timestamps; scenes 1–8.
- GT is used only post-hoc for diagnostics; it is not part of inference or cache construction.
- Raw CSV/JSON diagnostics are retained in the local/NAS experiment directory; this compact report is the versioned result summary.

## Measurements

| Audit | Result |
|---|---:|
| G0-A/G0-B alignment rows | 8,255 |
| G1 matched observations | 69,401 |
| G1 same-person pairs / geometrically consistent | 20,319 / 17,137 (84.34%) |
| G1 different-person ambiguous | 11,577 |
| G2 fused pairs | 17,100 |
| G2 correct / wrong fused | 14,925 / 2,175 (12.72% of fused) |
| G3 predicted identity switches | 20,146 |
| G3 wrong world-object merges | 2,319 |

The scene-level spread is substantial (especially Scenes 3, 6, and 7), so these numbers are diagnostic evidence only. The high G3 switch count is expected from the untrained/replay persistent bank and is not a final claim about the learned W4 route. The formal decision requires the complete 24-scene TRAIN audit, fixed model training, all 22 TEST videos, and official legal-scope evaluation.

## Reproducibility

The full preflight files are generated by the four audit scripts under `results/worldobject_train_preflight/` in the local worktree and are tied to the frozen cache manifest/source hashes. This report is pushed independently so the remote branch records the intermediate evidence without publishing large cache files.
