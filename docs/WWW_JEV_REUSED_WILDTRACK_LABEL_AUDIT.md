# 既有 WILDTRACK TRAIN 标注审计

发现并复用了Phase XIV已留存的前320份原始TRAIN共享标注，正文共10332875字节。每份SHA256与旧下载manifest一致；文件名从00000000到00001595，步长5，对应发布的2Hz标注时刻。未读图像、后40 TRAIN或最后40 TEST标注；没有下载数据、训练或GPU任务。

共有276个声明personID，其中265个跨帧重复；这些是标签ID数量，不能当作独立因果安全组。原始person/frame重复键0，视角键异常0，不完整七视角集合0，存在结构问题的原始帧0。不清除重复或改写GT；机械结构通过也不证明每条人工身份绝对正确。

共享GT实际含七相机投影，C1/C2单独统计。C1/C2有93个混合-1且正面积、有图像交集的框。旧准备脚本遇到任一坐标为-1就跳过；这里记录其与完整四坐标缺席哨兵的区别，不修订旧评价结果。全部缺席/边界/无交集计数见JSON。

同帧人物共现的保守连通诊断得到1个分量，最大276个ID。它不是原生Hungarian因果依赖图，也不能认证独立训练组。数据只有一个连续采集，整个前缀已作过离线评价，本轮固定为历史暴露的TRAIN审计人口；新RESERVED采集数为0。不按相机或时间再划出“独立验证”。

本轮确认了可复用的TRAIN路径与结构，仍未建立安全动作监督或独立RESERVED。原3 TRAIN/1 RESERVED、8＋3资格不变，不能启动依赖该资格的训练。下一步需要独立、合法的人工验证来源；MMPTRACK若有合法副本可继续审计。目录搜索有深度和数量边界，未找到副本不代表整机绝对不存在。

作者监督分割以最后40标注时刻为TEST，加载器的val变量不能解除保护：[补充材料第5节](https://openaccess.thecvf.com/content_cvpr_2018/Supplemental/1562-supp.pdf)。协议、原始计数、未读边界与哈希均已保存；未使用旧跟踪分数挑选输入。

后续离线GT读取器已在全部320文件核验通过，并通过6个边界/重复键检查。修正读取数13,754，旧格式13,661，差额93。仅返回离线身份与框，不返回GT世界坐标或生成在线policy输入。该结果保存于WILDTRACK_OFFLINE_GT_INTERFACE_AUDIT.json。旧跟踪分数未重算；未来方法对照必须统一使用同一冻结GT口径，不能把修正评价分母的变化归因为模型收益。
