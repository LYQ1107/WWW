# Ω-FullTrain MOT protocol

This branch studies supervised association learning for VGGT+GMT only. It is separate from JEV and from the earlier Ω-Corr row-replacement experiment. The locked machine-readable contract is [`manifests/omega_full24_training_protocol_v1.json`](../manifests/omega_full24_training_protocol_v1.json).

The unit of splitting is the complete VisionTrack TRAIN scene. The fixed 18/6 split is fit scenes 2, 3, 4, 5, 6, 7, 8, 9, 11, 12, 13, 15, 16, 17, 20, 21, 23, and 24, with validation scenes 1, 10, 14, 18, 19, and 22. It was written before any new model fitting; no scene or frame may be moved after inspecting scores. The existing GMT checkpoint was trained on original TRAIN, so this is not a backbone-unseen evaluation.

Every training example must come from a real causal GMT call. The current candidate history, the activated native association score matrix actually consumed by the Hungarian solver, thresholds, IDs, and final IDs are preserved. Ground truth is opened only after the inference and independent OFF-prefix parity check. Raw duplicate, conflicting, invalid, unknown, mixed, and ambiguous GT rows are masked; they are never repaired into labels. No GT-built ideal track, future frame, direct VGGT Top-1 replacement, or JEV component is allowed.

Stage A trains on the fit scenes and selects an epoch using validation only. Stage B refits the selected configuration on all 24 TRAIN scenes. Stage C runs the official TEST protocol once only after the legal GT/submission status is audited. If the local TEST annotations cannot be verified as an official legal evaluation interface, the result is `NOT_EXECUTED`, with an official submission artifact or a precise blocker instead of fabricated metrics.

The four pre-registered rows are: native-only residual head, frozen verified 512 VGGT fusion, task-adapted VGGT with rank-8 LoRA, and a matched frozen DINO control. All use a zero-initialized bounded residual, fall back exactly to native evidence when the external evidence is missing, and keep the GMT/native backbone frozen except for the declared adapter. Integration into GMT is permitted only after reliable geometry and a positive net identity correction gate on validation.

The full run produced fresh causal audits for all 24 TRAIN scenes (556,719 score rows; coverage PASS), Ω-512 2,048-dimensional frozen features and DINO 1,024-dimensional control features for all 24 scenes, and 54,053 masked listwise groups (41,576 fit / 12,477 validation). Stage A selected epoch 10 for all three executable heads, but the primary Ω seed had 0 validation fixes and 0 harms, so the locked Stage-A gate failed and GMT remains unchanged. A separate causal replay using the Stage-A Ω head found 6 accepted-primary fixes and 1 harm across the six validation scenes; this diagnostic is retained but cannot override the pre-registered gate. The rank-8 Ω LoRA path and official TEST evaluation are `NOT_EXECUTED`; no TEST ground truth was opened.
