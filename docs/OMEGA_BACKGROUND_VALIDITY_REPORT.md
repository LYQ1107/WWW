# Ω 独立背景验证

416主实验：**BLOCKED_WEIGHT_ACCESS / NOT_EXECUTED**。512仅为单独的固定样本诊断，不替代416，不代表身份或跟踪成功。所有24组及失败样本均保留。

SIFT与检测框屏蔽复用原geometry_confidence实现；原有all-point F/H及自拟合指标被丢弃。保存的putative matches按两侧原图坐标去重，避免同一SIFT位置多方向或many-to-one重复计数；不使用GT、模型残差或RANSAC mask选取评估点。4×4固定棋盘块分fit/eval，传统F只在fit拟合，所有模型共同在eval评价。这个工程去重规则在查看首批指标前提交，旧原始预处理指标保持不变。

固定主参考：至少20个eval点、12原像素内比例≥.25、中位数≤12原像素、凸包覆盖≥完整原图面积1%。阈值未降低；归一化残差单列。匹配不足、覆盖不足和预测F不一致分开记录，不能从这些数字断言无物理重叠。描述子匹配是可复核的putative对应，并非真实相机或三维GT。
