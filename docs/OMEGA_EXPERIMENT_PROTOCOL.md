# Ω 有限验证预注册

当前是准备阶段；没有Ω科学成功结论。全部原任务见 OMEGA_FINAL_GOAL.md。
主模型为官方416 reproduction，balanced、patch16、冻结全部权重，双图同一次forward。
若获得字节一致的512，仅单独运行同一固定首24组的自然场景诊断；不以512代替416。

1. 固定 `manifests/omega_fixed_pair_cohort_v1.json` 后方可执行Ω模型前向。
   首24组跨11个fit场景、均匀且不依赖GT。其余42组均匀+30组困难诊断已同时固定，
   只有主模型接口和可靠背景证据成立后再扩大。失败和缺重叠样本保留。
2. source/model/actual H/W、坐标变换、finite状态、SO(3)、原始像素F及物理相机顺序
   都必须记录。AB和BA联合前向分开计费，比较相对姿态与F转置尺度/符号等价，
   不比较跨forward绝对world坐标。
3. 背景匹配复用现有ORB/SIFT实现，屏蔽真实检测框、crop缺失和padding。
   先固定原图空间4×4分块棋盘分成fit/eval，传统RANSAC只在fit点拟合。
   旧VGGT/Ω/传统F在共同有效的eval点计算原始像素残差，不比较传统自拟合内点误差。
   putative descriptor matches不是GT三维对应；匹配不足不证明无物理重叠。
4. Ω可靠性主参考为至少20个有限独立eval匹配、12原像素内比例≥.25、
   中位数≤12原像素、两图凸包覆盖最小值≥完整原图面积.01。
   另报告对角线归一化残差和分位数，不因失败降低主门槛。
   少于3个时刻/2个fit场景可靠时只能做有范围的诊断，不准声称广泛可靠或准入完整视频。
5. 主比较是同物理图像对的旧VGGT/Ω416/传统几何。预处理分辨率及各自有效区域分开记录。
   512只作附加诊断。源码/坐标错误允许有限修复并保留失败日志；无工程错误但主几何持续
   无可靠支持时，出具POSE_NO_RELIABLE_SUPPORT，不无限扩样/调参。
6. 仅在背景几何成立后研究同步目标候选。先F-only弱框中心证据，再独立深度残差/置信度
   诊断；框中心不是真实同一物理表面点。G0/G1/G2/G3/G4/G5保持原任务含义。
   深度无独立证据则G4为NOT_EXECUTED。标签只能离线加入。
7. 保留全部原生错误、同步适用错误、可靠几何错误和纯净正例覆盖的不同分母。
   单行排序/矩阵变化/原Hungarian阈值Bank最终提交三层证据分开。
   先fit11，固定方案后才检查已接触标签的DEV12；不声称盲测。
8. 只有可靠几何+净正确实际决策增量有证据后才接入GMT get_asso；
   不替换backbone/GTA/RPCE/ReID/Hungarian/历史。lambda仅{0,.1,.3}、残差绝对值≤1，
   默认关闭；零lambda/零reliability原对象返回；仅当前时刻已发布对侧候选。
   原camera处理顺序不变，不补未来身份、不传播跨时间F。
9. 只有真实短前缀净决策收益后执行完整合法TRAIN，冻结后最多一次strictDEV5。
   不满足前序gate则不执行无机制依据完整视频；NOT_EXECUTED/NOT_MEASURED不得填0/PASS。
10. 首模型接口只用一张空闲GPU；最多0/4/5/6四张且重查他人进程。
    数据/几何研究缓存预算2GiB，权重和隔离环境分列；不缓存全视频dense tensors。
    端到端含加载/读图/预处理/几何/检测关联/导出，离线GT评价单独计费。

每个实际阶段保存输入与源码SHA、命令/环境、原始结果、失败原因，提交并推送核对远程。
准备完成、权重访问受阻、几何负结果、身份负结果和完整跟踪负结果具有不同含义。
