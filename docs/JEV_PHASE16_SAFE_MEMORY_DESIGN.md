# Phase XVI 安全记忆设计

P1 的五种冻结读取方案未达到预先冻结的支持增益门槛。继续增加原型、训练读取器不具备资格。本阶段单独检验 P0 已经观察到的错误写入反馈。参数与分支由 `P2_P3_PROTOCOL.json` 在结果出现之前冻结。

原生提交、Gallery、hits、Bank 和合法候选编号全部保持原样。独立匹配视图用原始 Gallery 行索引选择历史；WHO 仍为四槽，Q4 的前驱外观和几何从独立的已接纳状态读取。软可靠性仍由原生 posterior 更新，不另设 WRITE 学习头。

CONFIRMED 只表示规则一致性，不意味着身份正确或 GT 纯净。规则以最早同相机连续稳定三条真实观测建立固定外观锚点；余弦门槛 0.85，相隔不超过两个场景帧时归一化框平均 L1 不超过 0.05。有锚点且一致的观测接纳，不一致观测隔离。新身份需三条一致观测才确认；pending、quarantine 各保留至多四个行索引。完全没有已接纳证据的合法 ID 使用真实待确认或隔离观测作显式不可信 fallback。这是可失败的规则假设，不是纯净性证明。

五个预定规则为 always_write、recent_only、conservative_provisional、delayed_confirmation、bounded_quarantine。最后一个是预先选择的原生候选；其余用于影子写入比较。保留每条原始观测的状态记录，所以总元数据不是常数内存。额外持久外观向量为独立状态每相机的 sum、last、EMA，最多六条每 ID；锚点和队列只存原始行指针。禁止用影子缓存计时声称真实图像 FPS。

四组原生因果实验从完全相同的原始 XV 前缀和 RNG 出发。所有过去写入标记为 CONFIRMED_LEGACY_UNVALIDATED，不利用 GT 回溯清理。B、D 仅从干预时刻开始控制未来写入。C、D 使用 P1 未合格的 E 读取方案对目标行首次决策作固定负对照；之后所有组恢复同一个冻结四槽解码器，且各自继续运行真实变异状态。此实验不构成 E 的部署或收益资格。

任何严格前缀、任何预定 horizon 上，新混合、错误 owner 观测或传播时长、false_split_birth 恶化均否决安全资格；至少八个独立 cluster 的收益才可能通过。TRAIN14 因重复 GT 仅作诊断。DEV17/18/19 只能诊断，不选规则或门槛。未通过不得训练或宣称结构成功。
