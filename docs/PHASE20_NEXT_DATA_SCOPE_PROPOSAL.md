## 来源与访问

优先检查用户已有、获准科研使用的MMPTRACK TRAIN/VAL副本。其[官方网站](https://iccv2021-mmp.github.io/subpage/dataset.html)提供同步15FPS、校准、跨视角身份框标注及不同的TRAIN/VAL参与者，但下载需研究者签署使用条款并申请。代理未代签、未发邮件、未获得数据。若已有副本，只需提供服务器路径，不复制整库。

公共候选为[WILDTRACK](https://www.epfl.ch/labs/cvlab/data/data-wildtrack/)与[SCOUT](https://scout.epfl.ch/)。前者只有400个2FPS标注时刻，不能自动当成多个独立完整序列；后者发布说明仅序列1前8相机有完整人工标注，其余伪标签不能作严格GT。它们只是可用性候选，不能承诺补齐监督资格。公开文档已查；新数据图像、标签未读取。

## 本次建议授权的范围：仅A阶段

A1：确认可合法访问的来源、官方训练/验证分割元信息、人工GT标注类别、文件目录、格式、压缩/展开大小及独立人物/录制场次关系。仅使用TRAIN和允许作验证的VAL，不读取任何来源官方TEST。

A2：新增元信息和小标注清单累计≤64MiB，禁止下载视频/模型/完整图像包。MMPTRACK访问依赖已有合法副本或用户自行完成数据申请；本授权不包括代签或联系他人。若公开来源必须下载大包才能获得小量元信息，报告访问限制，不绕过预算。

A3：在任何新跟踪得分之前冻结实际文件SHA和人物/场次划分。不同相机、同一人物和同一连续录制不能跨TRAIN/VAL；同一人物跨场次的连接全部审计。官方VAL不作训练，未知人物重叠必须标UNKNOWN。不给Stage1未知预训练暴露做完全未见声明。

A4：审计原始GT唯一性、跨相机ID一致性、同步、帧率、bbox定义/遮挡定义。不同帧率下必须预注册原生frame-based stale规则与秒数含义，不能复制帧“补FPS”。不得以清除重复GT获得虚假的可评估PASS。校准只可用于真实detector框的几何投影，不把标注提供的GT世界坐标当作运行时视觉证据。

A5：输出SOURCE_ACCESS_AUDIT、LABEL_VALIDITY_AUDIT、PROSPECTIVE_SPLIT、RESOURCE_MANIFEST和下一实验可达性报告。若无足够人工有效、独立验证关系或来源不适合两摄像头native接口，明确否决该来源。最多3候选，冻结来源顺序，不按跟踪收益选数据。

## 暂不授权的B阶段

任何真实图像提取、原生轨迹/干预或controller训练都不属于A。只有A建立可用来源和可达样本人口后，才能给出一个具体的、预注册的B预算与公平对照方案。保留历史8＋3Gate，不回头改；新的Gate应针对新的研究人口和可提升空间设计，禁止数学上不可达的门槛，且保持原生有效、无泄漏、无崩溃、真实监督和独立验证等硬要求。
