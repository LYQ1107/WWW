# Native Causal Lifecycle MiniSet v1 schema

This decision dataset is derived from existing VisionTrack TRAIN videos, not a new raw-video benchmark. Its bounded construction is gated on completed P0.5 attribution. Train=07, validation=06; heldouts=09/10/11 never become training inputs.

Each JSONL record has a unique event ID, sequence/frame/camera/row, typed question, legacy and complete mutable-state fingerprints, snapshot SHA, seed/source/cache/checkpoint/evaluator binding, and independent `online` / `offline_only` objects. Snapshots retain complete branch-local trajectory RNG state and frozen perception references. The complete digest includes every mutable state field, counters and archival assignments; frozen perception content hashes are cached by semantic video/frame/view key.

`online` contains the 64 state features, actual detector ReID vector/confidence/box, semantic candidate IDs in original column order, raw GMT scores, full joint score matrix and proposal pairs, 12 candidate evidence fields, legal ACCEPT/REASSOCIATE/NEW, and factual action. Candidate fields are raw GMT score, relative proposed score, proposal indicator, competing proposed rows, history/memory counts, last-seen gap, observed camera fraction, active/stale flags, current-to-prototype appearance cosine and availability flag. A missing prototype has cosine=0 and availability=0. Numeric identity IDs never become network scalar features. Motion/depth/quality predictions absent from the real cache are omitted.

`offline_only` contains exact-image one-to-one IoU>=0.5 GT alignment, known correct candidate IDs, candidate miss versus unknown candidate identity, proposal correctness, H8/16/32 outcomes, action utility vector, finite normalized target probabilities, oracle feasible-action maximum, best set, margin, unknown/tie/censor flags and sample weight. First-known new-ID anchors are evaluated only inside each horizon. GT-unmatched and tied records have zero fitting weight. An unanchored candidate is not falsely called a confirmed candidate miss.

`branches` retains CONTROL and all three legal current-row interventions, first/second native decisions, banned edges, actual committed IDs and complete successor-state fingerprints, raw prediction/source SHAs, identical exogenous window and live common B2 continuation. Two predeclared real competing-row groups add OTHER_REASSOCIATE and JOINT_REASSOCIATE, enabling a direct nonadditivity diagnostic. Current frame through current+H inclusive is H+1 frames. Video-end truncation is explicit.

Sampling uses the first four eligible payloads in each of four equal exogenous frame bins. It is deterministic: inclusion is 1 for selected events and 0 otherwise. Selected/eligible fractions are descriptive, not random inclusion propensities. Save the complete unscreened MATCH distribution and bin counts; do not claim enriched-sample population rates.

The loader validates candidate order/shape, masks, finite values, normalized probabilities, oracle maxima, source digests, roles, uniqueness, zero unknown weight, branch horizons and factual/control parity. `inference_input()` returns only `online`. MEMORY/REACT records remain separate audits and explicitly blocked when their learnability/native gates fail; this loader does not pretend they form a successful Unified dataset.
