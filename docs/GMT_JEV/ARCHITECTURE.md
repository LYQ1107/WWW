# Minimal post-GTA correction

完整GMT先产生原生聚合Global ID分数；模块仅在首帧跨相机和后续MATCH入口修正合法分数。GTA/RPCE不替换，Bank恢复/WRITE/最终Hungarian不改变。

24维特征：真实GTA分数/竞争/熵、原生窗口支持数、已提交观测数量/年龄、同/异相机外观支持及矛盾、可观察历史一致性和检测置信度。仅维护每个已经提交ID的两相机外观向量和/数量/最后时刻摘要，不存独立Gallery，不用GT，不比较跨相机坐标。

32维共享证据与检测条件查询，CIC带两种可观察冲突角色；头输出sigmoid gate与tanh delta。硬风险门控满足支持/竞争/冲突条件后才干预，平均分数残差上界0.05，乘原始支持数加回原生总分。零初始化delta，初始gate0.5，初始梯度不消失。CIC4962/Attention4898/MLP5119参数，尚未训练，结构价值未建立。

GT由独立离线标注器消费：首次纯净>=3已知观测、>=80%覆盖，原认证owner在当前历史中仍>=80%纯净；全原生历史只存在一个兼容ID且它是当前合法active选项时才设唯一目标。别名、混杂、缺选项和未绑定当前检测均mask并统计。原始GMT产生的当前证据才可训练；旧JEV D0/D1不用。

目标唯一性补充（P1结果前冻结）：其他ID即使尚未达到3次认证，只要已有当前人物的纯净支持且纯度>=80%，也作为可能别名导致UNKNOWN。不能把未认证短ID伪装成错误负例。Bank仅统计原生实际查询和接受的选项，不从陈旧的可能成员表虚构合法候选。
