实际执行始终为完整冻结 GMT observe，保持原生提交和在线状态。复用只读离线认证观察器；每帧分别构造 CURRENT_GATE_ORACLE 与 ALL_LEGAL_DIAGNOSTIC_ORACLE。对认证唯一目标行，在允许边上给目标 +0.05、其他候选 −0.05，乘以原历史支持长度，使用同一原生 summed-score Hungarian 与严格0.1接受阈值。UNKNOWN 行残差为零。前者保持当前风险门控，后者仅在诊断中移除风险门控，候选仍完全相同；后者超出当前部署策略空间。

只统计假想 assignment，绝不提交 ORACLE 动作、修改 Gallery/Bank、改变未来实际状态或输入 actor。按原64帧时间桶记录原生错误行、允许边覆盖、目标边覆盖、目标分数在最大允许残差下仍无法通过 active-MATCH 阈值的数量，以及认证 accepted-reference N01/N10 和 UNKNOWN Bank 结果。再次核验完整原始 observe 诊断计数与既有覆盖报告一致。
