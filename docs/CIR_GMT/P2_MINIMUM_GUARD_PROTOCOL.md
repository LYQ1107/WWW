# Phase2 最小 Guard 冻结范围

本阶段与正在运行的3e6d6c5d固定C1开发对照隔离。先仅CPU读取原生FIT12缓存（4/5/6/7/8/9/12/13/17/20/21/24），不重新挖掘错误、不采集视频、不读取DEV成绩或TEST标签。原始矩阵先逐项复算原Hungarian/严格接受，再在同一原始历史上计算C1和风险证据；这是original-state replay，不能称作VETO净收益或在线HOTA。

唯一固定联合冲突规则需同时满足：已有身份接受、合法局部候选、同相机最近连续3帧相同原生ID、当前与上一帧一对一IoU至少0.7且相对竞争IoU裕量至少0.3、局部1152维余弦至少0.9、已选身份历史均值余弦低于0.7、归一化C1分配分数裕量低于0.02，并且局部ID与已选ID不同。SAFE仅表示这些观测支持当前局部关系；SUSPECT只是待验证风险，不是GT认证。其他均UNKNOWN/KEEP；不靠跨相机同时出现或单纯外观变化拒绝身份。

先封存所有GT-free策略输出及SHA，再解析已有独立离线监督。当前GT未知或选中原生ID所有权不可靠时risk label=null。错接受查询至少50、至少8个不同(scene,person)组和3个场景才足够考虑有界普通二分类风险学习；此准入不证明拒绝动作有益。是否做SPLIT/RELINK仍需真实配对变异未来与原生状态资格，不以错边标签直接代替因果效用。

有限必要对照：C1 KEEP、C1+上述联合规则、C1+普通归一化margin控制、C1+固定10%接受保护。若完整C1开发确有正向，则追加唯一固定bias+2阈值解释对照，区分历史余弦信息与简单降低拒绝率；它属于普通规则工程归因，不包装成神经网络创新。具体原生接入前固定动作接口/联合重求解/校验流程，所有规则得到同一合法VETO和求解器。不无限扫描阈值。
