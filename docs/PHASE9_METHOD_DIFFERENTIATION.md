# Phase IX method differentiation

CAMELTrack learns association context from temporal tokens and current detection/tracklet group interaction, with identity-supervised association-centric embedding loss and occlusion/gap-biased training frames. MOTIP predicts contextual ID words with causal history masks and a recyclable vocabulary. Ordinary DeepSets/attention and QDTrack competition normalization can explain context gains without a Question/Action hypothesis. Those code mechanisms are audited in PHASE9_EXTERNAL_CODE_AUDIT.md with fixed links.

Our testable candidate JEV proposal is: use state64 and candidate-relative evidence shared by ordinary networks; condition shared representations on WHO and candidate/NEW action tokens; separately predict current correctness and actually executed H32 counterfactual utility. Candidate correctness and future utility are not interchangeable. Absolute predicted/GT IDs are never learned inputs. Future labels arise only from real legal assignments, actual bank/birth/memory commits and live future proposals. This causal label construction is the current defensible methodological hypothesis, not demonstrated architecture novelty or superiority.

Scoring, constrained global assignment and native commit must be identical across fixed/dynamic rules, MLP, DeepSets/context model and JEV. The diagnostic GMT_OFF compatibility mode preserves historical Hungarian-then-threshold semantics; it is an anchor and must not be falsely called a candidate-values identical-objective architecture baseline. Shared learned comparisons use independent NEW dummy columns, the same legal mask and same per-camera capacity; lawful cross-camera identity reuse remains allowed. Ordinary score normalization, parameter/compute matching and correctness-versus-utility controls separately test competing explanations.

SUSHI's offline subsequence graph and StrongSORT post-hoc links may access future and are not imported into online inference. BoT/DeepOC memory EMA/motion changes are separate engineering improvements, not allowed to secretly alter the frozen MATCH comparison. MeMOTR memory informs a later independently gated study. We read upstream GPL StrongSORT without copying its source.
