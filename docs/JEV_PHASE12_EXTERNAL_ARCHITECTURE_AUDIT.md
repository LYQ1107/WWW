# Phase XII actual external architecture audit

Every implementation below was fetched and inspected at the exact commit in `EXTERNAL_CODE_MANIFEST.json`. This is an independently implemented Visual System-One / Jev-style MCMOT architecture, not a reproduction of private TypeSafe Jev or its RLCD. No third-party implementation is vendored.

| Source | Actual inspected computation | MCMOT adaptation / limitation |
|---|---|---|
| [Valen](https://github.com/Liuziyu77/Valen/tree/5f775c4f6747216d6085d088c9004af66371638d) Apache-2.0 | `ValenDualEncoder.encode_state`: text/vision projections, modality/coordinates and FusionBlocks. `encode_questions`: instruction-conditioned pooled query tokens then QuestionBlocks self/instruction/shared-memory attention. `score_questions`: dynamic candidate text pool, question/type initialization, CandidateBlock question and shared-memory cross-attention with shared K/V and chunks. | Separate state / question / option stages; replace text and DINO/Qwen with genuine frozen GMT ReID/history and numeric decision context. Dynamic candidate-wise weights independent of K. |
| [Valen Qwen heads](https://github.com/Liuziyu77/Valen/blob/5f775c4f6747216d6085d088c9004af66371638d/valen/modeling/qwen/heads.py) | Bilinear decision/candidate dot product; ordinary concatenation MLP; RoleMLP and Mixer read the same four roles, mix roles rather than candidate rows. Shared-state doc distinguishes processor reuse from actual shared backbone forward. | Ordinary similarity and MLP/SetTransformer controls are necessary. Naming an output head Jev is insufficient. No LM needed for tracking. |
| [Valen experimental RLCD](https://github.com/Liuziyu77/Valen/blob/5f775c4f6747216d6085d088c9004af66371638d/valen/training/rlcd.py) | Frozen per-batch categorical sampled actions/rewards, group-normalized advantages, clipped ratios, reference categorical KL and proper Brier auxiliary loss. Rewards combine target correctness and squared confidence error. SFT uses labeled candidate-distribution log loss. | Explicit local experiment, not proprietary RLCD. Phase XII uses partial-known conditional CE and executed native utility; no RLCD claim or fabricated rewards. |
| [OmniJev](https://github.com/tinnel123666888/OmniJev/tree/14dbec4f71e194852c8d7b88ab36ef639493f400) Apache-2.0 | `OptionScorer.logits`: option MLP multiplied by tanh(question MLP), scalar score / per-type exp temperature; optional LM six-feature residual. Softmax choice adds abstain logit; older sigmoid path leaves residual probability only if sum<=1, otherwise renormalization loses option-set invariance. Noul sigmoid, ordinal cumulative score head. | Actual dynamic question gate with normalized residuals. We use conditional masked softmax, explicitly do not claim absolute option-set invariant probabilities. Abstain risk is preregistered, untrained rather than arbitrarily calibrated. |
| OmniJev `records.py`, `infer.py`, `branch.py`, `templates.py` | Typed caller-specified legal questions/options. `system_one` supports shared state multiple questions; hybrid prefix cache forks real KV/recurrent states, independent option suffixes, question representation immediately before option marker. Per-type calibration; input panel/media cache. | Legal action spaces come from native tracker. Immutable visual sharing is permitted, state-dependent contexts rebuilt after commit. Does not imply three tracking tasks have labels. |
| [Visual-Jev](https://github.com/guanxuyu-sv/Visual-Jev/tree/a392eaedfa41adae348f9767b55c0f54b3a13b57) Apache-2.0 | VDM independent repeats vision; vision-cache reuses visual encoder; prefix-share prefills prefix then clones KV per question; batched suffixes preserve masks. Choice slots have fixed K_MAX mask, claim/answerability heads; LM option readout vs dedicated heads. Training uses independent-sample batching, frozen vision + language LoRA, CE/answerability/ranking/consistency variants and next-token baseline. | Learn actual sharing and independent readout idea; dynamic identity options replace fixed slot head. No private visual backbone, no LLM/autoregressive decoding, no importing evidence-degraded labels. |
| [NanoJev](https://github.com/TianyuCodings/NanoJev/blob/76fdfc9ecdca45a9bcef17991a07d3041a87685a/scripts/train_toy_decisions.py) MIT | Flat complete candidate paths; final hidden scalar plus ordinary candidate set self-attention residual using log candidate count. Boolean logits [0,z]; masked CE gold/validated identity teacher probability proxy. Toy training explicitly repeats prefixes, not prefix sharing. | Ordinary same-visual SetTransformer is a strong baseline, not final Jev. No teacher distributions or toy success transferred as tracking evidence. |

Public code supports these operations. It does not establish equivalence to TypeSafe private Jev 1.x, private RLCD, or online MCMOT gains. All new network code is written independently using PyTorch; citations and exact source/license hashes are retained for reviewers.
