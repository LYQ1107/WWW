# Architecture diagnosis

Current evidence: initial R3 typed JEV is worse than strong Fixed/Threshold; other ordinary new controllers also degraded. Same-state auxiliary head improvements did not establish causal association benefit. P1 actual native state mismatch is measured but its direction is heterogeneous. P2 tests data without architecture changes;300 source-state outcomes are local only.

One conditional P3 diagnostic was frozen before P2 full-online results and was activated when JEV D1 failed the HOTA and IDSW gates. It directly optimizes and submits scores for every legal active identity using one Hungarian; joint-plan value is disabled. M1 retains shared state, typed questions and candidate-specific readers. M2 gets the same inputs, labels, schedule, losses, lawful solver and active parameter capacity with an untyped third context Reader. M1/M2 compares the complete typed and untyped readout variants, including reader allocation; it does not isolate question embeddings alone. Comparing either with M0 also changes score-readout/loss/solver and cannot be called pure architecture causality.

Existing hooks, temporary forward substitutions and runtime solver replacement are tested on actual native inputs for restoration after success and injected exceptions, permutation semantics, illegal masks, capacity and zero-residual output. Those tests passed and do not establish a previously undetected engineering cause. Actual submitted active choices and subsequent native state updates also matched journals; UNKNOWN remained masked. No growing family of questions/readers or future-safety training is admitted.

The same contracts also pass with the final 1000-step D1 and direct checkpoints, rather than only their initializers. Candidate permutation changes scores by at most 3.82e-6 and preserves the actual chosen native identities. See TRAINED_CONTRACT_TESTS.json and TRAINED_DIRECT_CONTRACT_TESTS.json.

Full TRAIN16 shows limited JEV data benefit (+0.132 HOTA, IDSW1581→1891), while ordinary Attention gains +1.467 HOTA. Direct JEV reaches HOTA67.052 versus its matched direct ordinary variant63.097, but remains below the stronger ordinary Attention D1 at68.892, frozen Fixed69.710 and Threshold70.605. Against unchanged JEV D1, direct JEV reduces IDSW1891→1093 while CVIDF1 falls83.511→82.406 and full-video identity inconsistency grows6957→7741 camera-frames. Unmapped fragment observations rise3118→5700. This is a stability tradeoff, not evidence that the typed architecture solved identity propagation.

The label-alias audit finds multiple certified compatible native IDs in697/47860 D0 positive-supported gradient rows and195/14002 self-prefix positive-supported rows. Current compatibility supervision can therefore fail to select a unique persistent identity. This is an observed alignment limitation, not an experimentally isolated principal cause. All new native comparisons use one seed and pre-exposed TRAIN16; no independent scientific advantage is established.
