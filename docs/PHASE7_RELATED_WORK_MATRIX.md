# Related work audited through 2026-10-07

Primary PDFs were downloaded and parsed; source SHA/page counts are in
`reports/JEV_PHASE7/PAPER_SOURCE_MANIFEST.json`. Pinned repositories and named files are in
`EXTERNAL_SOURCE_AUDIT.json`. Download availability is distinct from function review and
reproduction. None of these papers' numerical benchmark results is claimed reproduced here.

| [LA-MOTR](https://openaccess.thecvf.com/content/ICCV2025/html/Wang_LA-MOTR_End-to-End_Multi-Object_Tracking_by_Learnable_Association_ICCV_2025_paper.html), ICCV 2025 | Separate detection and tracklet branches; spatially guided learnable association and subsequent tracklet updates. | Advertised `PenK1nG/LA-MOTR` returns GitHub 404 at audit; no source commit invented. Also read [ByteTrack ECCV 2022](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136820001.pdf)
and pinned `BYTETracker.update`; its high/low cascade is a separate traditional control. Missing
low detections prevent attribution to its second stage; the available-input run is labelled accordingly.

WHAT DID WE LEARN? Learned association, NEW identities, lifecycle policies, typed memory control
and adaptive banks all have precedents. A possible contribution must be demonstrated native
long-horizon decision supervision, candidate interaction and error propagation beyond matched
ordinary controllers. Merely adding the Jev name or three semantic questions establishes none.
