# π³ 与 VGGT-Ω 双视角对照结果

本次实验在独立研究分支 research/pi3-omega-pair-comparison-20261022 完成，没有修改 GMT 的配置、检测器、关联器或轨迹状态。目标是在同一批 VisionTrack TRAIN 双视角图像上，对原版 π³ 和已经核验的 VGGT-Ω 512 原版权重做速度、几何一致性和同人排序对照。

## 固定协议

- 样本固定为此前冻结的 18 个场景、每场景 10%、50%、90% 时间分位点，共 54 对；没有按输出挑样本。协议文件的 SHA256 是 c3b8a0836d59992857a7766392678547dcb678c349c35ea01790fb2dba6c2f4a，上游冻结样本清单 SHA256 是 14199fe76c57d23a5aaa8e4789407ae9d284aca32e7a8372630478e2d6dad196。
- 两个模型都收到同一对原图，统一用 PIL BICUBIC resize 到 B=1,S=2,3×336×560，像素范围 [0,1]。该尺寸同时满足 π³ 的 14 patch 和 Ω 的 16 patch；原始 16:9 图像固定做轻微宽高比变形，两个模型完全相同。
- Ω 使用官方 vggt-omega 提交 48b23c8 和原版权重 vggt_omega_1b_512.pt，SHA256 c02da418b18bb01d0392598d3f6147366bcde1bb70fd08a5e3bf7925b0667934。
- π³ 使用官方 Pi3 主分支提交 9fa3ddb 的原版 Pi3，不是 Pi3X；权重 SHA256 为 33580e4702ac671558aedeab1148fd08118f7ce45bdbeb99f3e3cf340062875d。
- 四张卡为 V100-DGXS-32GB：3、4 号卡跑 Ω 的两份复跑，5、6 号卡跑 π³ 的两份复跑。两份复跑的 points 和 confidence 逐文件最大绝对差均为 0，说明结果不是单卡抖动。
- 两模型均使用显式 FP16 AMP，输出头保留官方 FP32 路径。没有使用 V100 上的 BF16 仿真。

## 速度

这里的 FPS 单位是“一次同步双摄像头时间戳”；若换算成单路摄像头图像吞吐，数值乘 2。模型耗时是同步后的纯模型前向，模型+解码还包括把输出转成统一世界点图。在线模块端到端包括 RGB 读图、resize、H2D、模型、世界点解码和固定检测框的几何同人排序；SIFT 质量检查和 NPZ 归档在计时外。

| 指标（54 对） | VGGT-Ω | π³ | π³ 相对 Ω |
|---|---:|---:|---:|
| 模型前向均值 / P50 / P95 | 142.8 / 137.1 / 167.8 ms | 180.4 / 177.0 / 202.7 ms | 慢 26.4%（均值） |
| 模型+世界点解码均值 | 148.5 ms | 186.3 ms | 慢 25.4% |
| RGB→在线关联均值 / P50 / P95 | 335.2 / 281.5 / 669.4 ms | 375.6 / 306.8 / 690.2 ms | 慢 12.1% |
| 模型-only 双视角 FPS | 7.01 | 5.54 | Ω 快 26.4% |
| RGB→在线关联双视角 FPS | 2.98 | 2.66 | Ω 快 12.1% |

我另外用同一个未改动的 GMT 检测器做了一次独立实测：检测器读图加两路检测均值 198.5 ms（P50 197.0、P95 214.6 ms）。把这个真实检测器时延串接到两个模型的在线路径后：

| 合成范围 | VGGT-Ω | π³ |
|---|---:|---:|
| 检测器+重建+关联均值 | 533.7 ms | 574.1 ms |
| 合成双视角时间戳 FPS | **1.87** | **1.74** |
| 合成单路图像 FPS | 3.75 | 3.48 |

这个合成值不含 GMT 的跨帧轨迹更新、全局 assignment、渲染或写盘，因此不能称为完整 GMT 视频 FPS；它是将实测检测器与两个几何模块串行组合的实时模块上限。

## 重建质量代理

VisionTrack TRAIN 没有可直接用于本实验的多摄像头 3D/camera ground truth，所以没有报告米制绝对误差。两个模型的输出都转为共同世界点图，在原图 SIFT 固定匹配上比较两视图世界点差异；数值是按该对场景尺度归一化的中位距离，越低越好。54 对全部有有效 SIFT 匹配。

| GT-free 跨视角世界点一致性 | VGGT-Ω | π³ |
|---|---:|---:|
| 54 对中位数的中位数 | **0.502** | 0.955 |
| 54 对中位数的 P90 | **1.353** | 1.947 |
| 每对误差 P90 的中位数 | **1.124** | 2.035 |

这说明在共同输入和共同世界点比较下，Ω 的几何相互一致性更好。它是重建质量代理，不是有 3D GT 的绝对精度证明。

## 同人关联排序

检测框来自一次独立实测的原始 GMT 检测器；检测器输出在两个模型间冻结。模型输出只负责几何排序。随后才读取 TRAIN GT，以互为最佳、IoU≥0.5 的检测框匹配实例 ID；任一图像中重复 instance_id 的 GT 行全部排除。只有另一视角同时存在已知正例和已知负例的查询才计入，因此 764 是相关的双向查询数，不是 764 个独立人物，也不是开世界拒识指标。

主指标是检测框内 5×7 点云的对称世界点 Chamfer 排序；辅助指标是框内世界点中位数质心距离排序。两者都取距离更小者为同人候选。

| 关联排序 | VGGT-Ω | π³ | π³−Ω |
|---|---:|---:|---:|
| 世界点 Chamfer：正确 / 计入 | 580 / 764 = **75.92%** | 603 / 764 = **78.93%** | +3.01 个百分点 |
| 世界点质心：正确 / 计入 | 553 / 764 = **72.38%** | 587 / 764 = **76.83%** | +4.45 个百分点 |

按 18 个场景做成对 cluster bootstrap（10,000 次）：

- Chamfer 的 π³−Ω 差值为 +3.01 个百分点，95% 区间 [-0.62, +5.64]，区间跨过 0。
- 质心的 π³−Ω 差值为 +4.45 个百分点，95% 区间 [+0.75, +6.87]。

因此 π³ 在这套框内点云排序上有小幅优势，但优势依赖于排序定义；Ω 的重建一致性和速度优势更稳定。两种模型在本评估中所有 764 个查询都得到了唯一有效候选，没有产生可报告的弃权；这不代表它们在开放世界或遮挡场景下具有拒识能力。

## 结论与 GMT 接入建议

在当前固定工作点上，若优先考虑“几何可靠性 + 实时性 + 接入风险”，**VGGT-Ω 更适合作为 GMT 的第一候选**：模型前向约快 26%，合成检测器端到端为 1.87 对/秒，且跨视角世界点一致性约为 π³ 的一半。π³ 的优势是框内同人排序高约 3–4.5 个百分点，但它的跨视角点一致性更差、模型更慢，且 Chamfer 差异的场景置信区间包含 0。

这还不是 GMT 接入批准。下一步若要接入，应在独立的连续验证流上把 Ω 的几何分数接到 GMT 的影子判定器，继续沿用固定门槛、失败样本和净纠错门槛；本次实验没有改 GMT 主流程，也没有宣称对 GMT 全局 MOTA/IDF1 有提升。
