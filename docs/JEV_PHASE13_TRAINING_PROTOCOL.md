# Frozen learning protocol

Read reports/JEV_PHASE13/TRAINING_PROTOCOL.json for exact hashes, seeds, Tiny selection and gates. Smoke/invariants and real GTA-free/native lifecycle pass first. Tiny1000, Pilot1000, then each method receives a fresh common20,000 AdamW updates, batch4 full natural camera payload groups, LR1e-4, weight decay.01, clip1, FP32. Seeds20261008/09/10. No Tiny/Pilot weights initialize formal models.

Labels are partial: multi-positive certified-option CE, .25 structured loss-augmented capacity-one assignment margin, .1 Brier. UNKNOWN candidates never become negatives; calibration is conditional on certified choices. Development groups at every32nd frame form the frozen audit/calibration subset; HOTA cannot select checkpoints or hyperparameters. Primary checkpoint is LAST at common20k; BEST is diagnostic. Formal tasks are MATCH only; REACT .75 cosine and native MEMORY WRITE fallbacks are identical across all methods.

Tiny includes later ordinary states from each TRAIN video, cross-camera, competition, hard positive, real stale and real scene-new/empty candidate groups selected solely by labels before optimization. Tiny recovery memorization cannot qualify the rare REACT task for formal learning.

After normal association is learned, at most one own-state TRAIN rollout/relabel/4k fine-tune round is allowed. All main style baselines receive their own same-sized round; comparison at total24k is separate from20k. Contamination remains UNKNOWN. Three-task lifecycle and heldout remain NOT_RUN until support/science gates qualify; inherited feature-pretraining exposure prevents independent heldout authorization.
