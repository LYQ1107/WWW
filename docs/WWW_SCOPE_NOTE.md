# WWW scope and deadlines

[Official WWW 2027 Research Track CFP](https://www2027.thewebconf.org/research-track-papers/) checked 2026-10-14: abstract 2026-10-18 AoE and full paper 2026-10-25 AoE. These correspond to 2026-10-19 20:00 and 2026-10-26 20:00 Asia/Shanghai. Track: Web Mining, Multimedia and Multilingual Content Analysis.

The CFP requires an explicit Web-related scientific challenge on the first page. Merely using a Web dataset or API does not establish relevance. VisionTrack is an existing aerial tracking installation; download/access provenance and an actual Web serving/retrieval application have not yet been verified. This is a material submission-fit risk, not a reason to stop the technical experiments.

Proposed measurable task: cross-video target/track retrieval, with a query from one camera and gallery from other streams, identity labels restricted to allowed TRAIN development scenes. Report Recall@K, MRR, query latency including feature availability, stream count and geometry-call budgets. Two-view VisionTrack alone cannot demonstrate arbitrary stream-count scaling or a production Web deployment. No WWW relevance or PAPER_READY claim yet.
