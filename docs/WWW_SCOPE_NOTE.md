# WWW scope and deadlines

[Official WWW 2027 Research Track CFP](https://www2027.thewebconf.org/research-track-papers/) checked 2026-10-14: abstract 2026-10-18 AoE and full paper 2026-10-25 AoE. These correspond to 2026-10-19 20:00 and 2026-10-26 20:00 Asia/Shanghai. Track: Web Mining, Multimedia and Multilingual Content Analysis.

The CFP requires an explicit Web-related scientific challenge on the first page. Merely using a Web dataset or API does not establish relevance. VisionTrack is an existing aerial tracking installation; download/access provenance and an actual Web serving/retrieval application have not yet been verified. This is a material submission-fit risk, not a reason to stop the technical experiments.

Proposed measurable task: cross-video target/track retrieval, with a query from one camera and gallery from other streams, identity labels restricted to allowed TRAIN development scenes. Report Recall@K, MRR, query latency including feature availability, stream count and geometry-call budgets. Two-view VisionTrack alone cannot demonstrate arbitrary stream-count scaling or a production Web deployment. No WWW relevance or PAPER_READY claim yet.

The source-33be4152 retrieval prototype now reads real dataset frames, runs causal frozen GMT and publishes bounded other-camera trajectory clips. Query targets are detector outputs selected on fixed rounds; GT is used only after publication for evaluation. Actual GPU prefixes preserve causal GMT predictions and produce measurable query responses/latency. This supplies a runnable retrieval experiment, with full videos, more stream counts and keyframe budgets still pending. Local replay is not evidence of Internet-origin streams, deployed web traffic, network scalability or a new Web contribution. The publication-fit risk remains.

Full causal two-camera retrieval evaluation is now complete for scene18. Native GMT is stronger than the initial frozen VGGT association-head residual transfer (Recall@1 97.73% versus90.29%; MRR .9879 versus.9246). These scores use fixed detector-query rounds, actual current/past clip publication, raw-GT evaluation only after running, full candidate ordering and explicit detection/gallery eligibility. Actual ten-camera prefix tests also preserve isolated GMT identities and query/gallery prefixes. This establishes an executable local multi-source content-retrieval experiment, with no positive VGGT-specific retrieval or Web deployment/novelty conclusion. Four-camera full runs, additional stream counts, keyframe budgets and consistent candidate-score controls are pending.
