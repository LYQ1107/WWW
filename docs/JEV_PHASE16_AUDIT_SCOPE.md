# Phase XVI audit interpretation

P0 retains the original raw committed Gallery, hits, native Bank and all real
ID outputs. Its ledger is an append-only forensic observer. It deliberately
stores the full actual raw history for the evidence-availability question;
it is not the bounded deployment matching view proposed for P1/P2.

Three quantities must stay separate:

- A historical observation aligned to the current person's offline GT shows
  person content. It does not certify the Global ID that owns this history.
- A WHO certificate needs at least three known observations, at least 0.8
  known coverage and one observed GT in the entire past ID history.
- An immutable owner anchor is established at the first past time satisfying
  that certificate. Later contamination cannot silently relabel the owner.
  Histories mixed before an anchor remain unanchored.

UNKNOWN is never a certified wrong identity. Actual commits into a mixed
history can nevertheless increase mixing or prolong a known owner error;
these consequences are reported separately from certified WHO selection.

P0's raw-versus-summary cosine gap identifies information available for a
bounded trial. It does not establish that a new token retrieves the correct
owner or that its use improves future identity state. Positive retrieval,
false activation and actual mutated-state native futures remain required.
All-query and commit denominators differ because MATCH DEFER can lead to a
second REACT query for the same eventual output detection.

The A–G mechanisms overlap. C's pending-promotion proxy is conditional on
the native DEFER and nonempty-old-instances gates, so it is not an assertion
that every such ID was actually offered. D records lifecycle exclusion,
not a demonstrated illegal candidate or erroneous state transition.

The four original full-video workers used a missing duplicate prediction
path at final aggregation. Their complete, closed native query/commit
traces can be postprocessed using the actual frozen detector outputs and
checked against the correct referenced Phase XV predictions. This performs
zero new model or optimizer steps and keeps the original exception logs.
No missing restorable native-state snapshot or latency is invented.

All frozen TRAIN12/13/14/16 and reused DEV17/18/19 runs are retained. TRAIN14
has duplicate raw GT and remains a separate diagnostic, excluded from
strict causal/label qualification. SEALED20/21/22, official TEST and Full24
remain unauthorized. Stage1's known all24 exposure precludes a claim of
completely unseen full-system generalization.
