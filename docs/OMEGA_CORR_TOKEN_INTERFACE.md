# Ω-Corr 真实Token接口

源版本339609f5，官方512原版严格1411键加载、全部冻结。首个冻结真实图像对的官方输入为[1,2,3,384,688]；网格24×43，排除17个特殊token后四层4/11/17/23均[1,2,1032,2048]，前后各1024维。

受控FP16测试执行2次原始无hook完整官方前向、1次有hook联合前向、两张图各1次真正独立单视图完整前向，合计5次；不能只用hook内部计数3冒充总调用。原始重复和hook的相机/深度/置信度等所有返回值均逐位相同、最大绝对差0。没有根据输出变化宣称机制收益。

完整子进程65.198秒（含导入、源码/权重校验、模型构建、预处理、5次前向及导出）；这不是部署速度。分前向CUDA同步用时与显存峰值见results/omega_corr_token_interface_v1.json。此阶段没有身份评分、模型训练或新F扫描。

坐标使用已有PixelMapping：框边界A_edges，真实patch中心16*(index+.5)-.5，通过A逆映射原图。完整patch必须位于有效真实缩放图像内；padding与部分padding不参与。每ROI最多16个不同真实patch，无插值或复制；不足两个不得输出多点循环成功。三个CPU合约测试通过。

硬最近邻A→B→A返回比例与mutual覆盖在数学上相同，不能作为两个独立创新增益；另保留软循环和局部一对一对照。所有指标仍只是视觉对应，独立可靠F支持另标。
