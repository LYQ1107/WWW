# Phase 2：预注册的候选身份状态预测增量

正式训练之前冻结 PHASE2_MATCHED_PROTOCOL.json，CPU 上运行七个独立同容量模型。每个模型分配 38,225 参数；普通排序/对比/无不确定性版本有 17 个不参与推理的方差头参数，去相机和去时间版本的显式输入通道被置零，具体激活参数量分别登记，不能仅以分配数声称完全相同激活容量。

所有模型使用共同 113,415 查询，每轮按 Phase 1 相同场景排列无放回访问，批量为每模型 1 查询，AdamW、种子、裁剪与更新次数相同。固定在第 1、3、5 轮完整覆盖后评价，不选择有利端点。CPU 总墙钟上限为 6 小时，不登记新 GPU 额度。达到上限保存真实断点并标记未完成，不缩短统计分母或假称全训练完成。

输入为原生严格过去历史的完整 1152 维特征均值，以及目标相机、跨相机支持比例、历史年龄、最近异相机间隔、支持数、集中度及跨度分组。时间单位为原生帧序号，尚未认证物理秒。跨度边界只用 11 个 TRAIN 的原生输入确定：最近异相机间隔的 25/50/75 分位为 1/1/16 帧；按事先规定的重复边界递增规则得到 1/2/16。原生候选调用状态共享人物和观测，不作为独立样本。

预测器只读取历史与条件，输出轻量低秩残差均值和裁剪方差。当前查询仅用于打分及离线 stop-gradient 训练目标。增量为预测余弦相对历史余弦的变化，裁剪后乘以支持和不确定性门控，再加到 C1 上。无增量精确恢复 C1，单边修正绝对值不超过 0.5。原生候选、完整联合求解矩阵、阈值及状态规则保持原接口。

比较普通排序、普通对比、异方差预测、无不确定性、无相机、无时间、同相机目标。原有逐观测 CV-PIL（Phase 1 C3）作为相同完整查询访问量的参考；两种架构不同，不能声称优化轨迹相同。普通排序器与新预测器具有相同结构、相同候选状态和更新预算。

异方差目标为余弦误差/方差加 log 方差，方差限定在 [0.05, 4]。这不是身份正确性的概率模型。开发评价将记录查询级预测误差与方差的关系、固定分组及方差是否塌缩为常数，别名候选在查询内汇总，人物依赖另计。

实现测试确认 UNKNOWN 不作为认证负例、预测器不读取查询、显式条件消融有效、修正有界及 C1 精确回退。真实 11 场景各中点与最大历史候选的 22 个查询完成独立模型对向量化实现的影子更新核验，所有影子权重丢弃，非正式训练成果。分数差上界约 3.82e-6，参数差约 1.32e-6，损失和 C1 基线一致；不声称优化逐位一致。

若预测无法超越 C1 与普通学习器，则记录负结果，并依任务书停止复杂预测组合；仍完成预注册的低成本历史可靠性和普通原生决策对照。任何此阶段重放正向都不能自动准入在线，强普通决策感知对照与完整因果接口仍须通过。
