# PIRGA 审稿问题与当前证据

本文件为研究进度，不是已成立的论文贡献。完整原始结果、检查点 SHA 与资源记录见 results/PIRGA_FULLTRAIN。

原C2/C3/C4已完成固定五轮与1/3/5轮完整开发重放，三个终点均无超越C1的独立预测收益。第5轮C3只有1修复、2已认证反改错、2原始正确→UNKNOWN及5原始UNKNOWN→已认证错误，C4为2修复/2反改错；C1仍为7/1。训练端目标不单调，不能宣称已经收敛或将下降唯一归因为过拟合。GPU→CPU执行数值及完整证据接口变化均已披露。旧接口第3轮C3为5修复/0已认证反改错/2正确→UNKNOWN/2原UNKNOWN→错误，同样无独立收益；仅第5轮尚待完成。

最新固定第3轮：新预测七模型均修复7个原始漏关联、已认证反改错1个，逐查询修复集合与C1一致；A4的原始无法认证→已认证错误为1，无不确定性和同相机目标为0。强普通D1/D2均为8修复/1反改错/2原始无法认证→已认证错误。裁定为NO_PREDICTION_SPECIFIC_GAIN，第5轮继续。旧预处理全量对照第1轮C3亦为7/1/2，不超越C1；各端点均非完整在线。

第3轮推理方差门控的同检查点完整ON/OFF诊断已完成：最大候选状态方差0.62977，超过1为0；全部分数和主关联动作相同。与第1轮一致，当前没有推理方差门控的决策贡献，不能用训练NLL改变均值来替代这个因果检查。

1. **为什么 C1 已有效还需要预测？** 原C3固定1/3/5轮均没有相对C1新增净修复，第5轮明显退化。新有界机制第1、3轮与C1的修复集合完全相同。当前没有独立预测收益，不能用C3超过较弱C2的差异掩盖C1；新机制固定第5轮和旧输入接口的覆盖配对仍在继续。
2. **为什么不是普通 MLP？** 新预测七模型包含同结构普通排序和对比目标；另有38,204参数的强普通配对MLP及相同结构的原生margin版本，接近38,225参数预测模型。两普通模型相同全部原生输入和训练访问预算；不同架构的输入形状和状态使用方式明确披露，不声称优化轨迹一致。
3. **跨相机条件是否必要？** 原C3第1轮比C4多修复1个，但C1解释C3全部修复；第5轮C3反而少于C4。新机制第3轮去相机、去时间、同相机目标的修复集合也全部与C1相同。因此没有跨视角条件独立贡献证据，固定第5轮继续，不能挑选某个较差消融的额外错误作为机制成立证明。
4. **不确定性有用吗？** 第1轮方差不是常数，但预测误差相关约0.183、已认证主关联错误相关约0.047，均为暴露开发数据上的描述性关系。进一步同权重门控ON/OFF审计显示所有候选方差低于门控起作用的1，分数和动作逐项相同。因此此端点的推理不确定性门控无决策贡献；NLL训练对均值的影响与推理门控应分开。目标非身份概率，后续固定3/5轮继续，不据此修改本轮门控。
5. **可靠性是否只是时间衰减？** 六个固定历史聚合已经同范围重放。多数与均值同为7修复、1已认证反改错；最近1条多修复1个，但也多出现1个原始无法认证→已认证错误。固定规则尚无足以准入在线的收益，学习式可靠性及预测组合不能据此宣称必要。
6. **决策损失是否改善最终身份？** 普通rank与native-margin已完成五轮训练及全部1/3/5重放。共同域第5轮D2比D1多1修复，也多1个原始UNKNOWN→已认证错误，额外修复仅1个人物组；扩展正例域D1/D2同为8修复，D2仍多1个UNKNOWN错误。没有稳健独立价值或在线准入证据。竞争输入保留全联合矩阵，计算固定其他C1行下的精确分配机会代价；这不是完整在线传播或全学习矩阵求导。共同域D2实际有565,149次非零梯度更新，不能用“未得到梯度”解释结果。实际完整Hungarian重放和闭环评价仍须分开。
7. **是否只修复漏接？** 当前第1轮 C3/C1和固定聚合规则的新增修复均为 missed_known_positive，未修复错误接受。后续按原始错误类型单列；拒绝无合法正候选的错误不能算身份复用纠错。原始正确→错误、正确→UNKNOWN、原始无法认证→已认证错误分别保留。
8. **是否仅靠更多训练数据？** 主要同预算对照共同使用113,415有效查询/轮、11场景、139场景—人物组；排序113,197，预测73,715，218个预测独有访问不制造C2假负例。旧300步仅274不同查询的原始证据保留。新旧训练还存在历史证据范围扩大，不能把所有差异只归因于数量；旧输入接口的106,800查询与原日程300步已单独配对，不能与主共同域声称完全相同预算。
9. **是否跨场景/人物/种子稳定？** 训练覆盖11场景，当前开发仅固定且已暴露的TRAIN12，一个主种子。人物分组和查询数分开报告，重复候选不作为独立样本。24场景OOF、第二种子及独立在线验证尚未运行，不声称独立泛化或统计显著。
10. **WWW贡献在哪里？** 目前无新的Web实体检索、身份索引或在线Web视频部署实验。不能通过改标题或将相机重命名为Web流构成贡献。质量与效率门槛通过后仍需真实、可审查的应用证据。

补充：新有界模型若不修复错误，必须区分学习机制失败与合法动作范围限制。已在新预测开发结果之前预注册全联合区间诊断。GT辅助区间见证只说明任意边分数扰动的可能性，不是可部署策略或学习式性能；不会据其改分数上限、阈值、候选或训练终点。

Q8归因补充正在执行：全3,000旧actor输入、正例集合与旧输入完全一致，但19训练资格查询存在负例认证掩码更保守的差异（旧300日程访问2条）。不把未知伪装成负例；新增同保守掩码的原300日程重训与旧Top8/latest4接口全106,800查询固定1/3/5轮配对，分离监督策略、覆盖与完整证据范围。旧300结果和严格等价失败核验均保留，结果未完成前不对数量因素下最终结论。

Q7作用范围补充：6个错误接受中3个无合法纯净正候选，另3个被新有界模型的原始状态区间证书排除（1个阈值、2个联合分配）。因此本轮缺少有界新模型可复用正确身份的错误接受机会，不应据此否定所有预测表征。拒绝错误边另行统计，不当作正确身份复用；已发布端点两者均未实现。该排除不适用于旧无相同上限的预测头，也不证明完整在线较早干预不能改变后续状态。
