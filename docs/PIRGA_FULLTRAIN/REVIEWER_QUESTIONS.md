# PIRGA 审稿问题与当前证据

本文件为研究进度，不是已成立的论文贡献。完整原始结果、检查点 SHA 与资源记录见 results/PIRGA_FULLTRAIN。

1. **为什么 C1 已有效还需要预测？** 第1个完整训练 epoch 中 C3 与 C1 修复集合完全相同，均为7个原始错误、1个原本正确的已认证反改错。当前没有独立预测收益，不能用 C3 超过 C2 的差异掩盖 C1。原训练轮数对照继续，新有界增量机制仍在训练。
2. **为什么不是普通 MLP？** 新预测七模型包含同结构普通排序和对比目标；另有38,204参数的强普通配对MLP及相同结构的原生margin版本，接近38,225参数预测模型。两普通模型相同全部原生输入和训练访问预算；不同架构的输入形状和状态使用方式明确披露，不声称优化轨迹一致。
3. **跨相机条件是否必要？** 第1轮 C3 比 C4 多修复1个原始错误，但C1仍解释C3全部修复。这不足以证明相机条件创新。去相机、去时间、同相机预测目标的固定消融正在训练，不能提前宣称跨视角机制成立。
4. **不确定性有用吗？** 第1轮方差不是常数，但预测误差相关约0.183、已认证主关联错误相关约0.047，均为暴露开发数据上的描述性关系。进一步同权重门控ON/OFF审计显示所有候选方差低于门控起作用的1，分数和动作逐项相同。因此此端点的推理不确定性门控无决策贡献；NLL训练对均值的影响与推理门控应分开。目标非身份概率，后续固定3/5轮继续，不据此修改本轮门控。
5. **可靠性是否只是时间衰减？** 六个固定历史聚合已经同范围重放。多数与均值同为7修复、1已认证反改错；最近1条多修复1个，但也多出现1个原始无法认证→已认证错误。固定规则尚无足以准入在线的收益，学习式可靠性及预测组合不能据此宣称必要。
6. **决策损失是否改善最终身份？** 普通rank与native-margin对照正在训练。竞争输入保留全联合矩阵，计算固定其他C1行下的精确分配机会代价；这不是完整在线传播或全学习矩阵求导。实际完整Hungarian重放和闭环评价仍须分开。
7. **是否只修复漏接？** 当前第1轮 C3/C1和固定聚合规则的新增修复均为 missed_known_positive，未修复错误接受。后续按原始错误类型单列；拒绝无合法正候选的错误不能算身份复用纠错。原始正确→错误、正确→UNKNOWN、原始无法认证→已认证错误分别保留。
8. **是否仅靠更多训练数据？** 所有对照共同使用113,415有效查询/轮、11场景、139场景—人物组；排序113,197，预测73,715，218个预测独有访问不制造C2假负例。原300步仅274不同查询的证据未覆盖。新旧训练还存在历史证据范围扩大，不能把所有差异只归因于数量。
9. **是否跨场景/人物/种子稳定？** 训练覆盖11场景，当前开发仅固定且已暴露的TRAIN12，一个主种子。人物分组和查询数分开报告，重复候选不作为独立样本。24场景OOF、第二种子及独立在线验证尚未运行，不声称独立泛化或统计显著。
10. **WWW贡献在哪里？** 目前无新的Web实体检索、身份索引或在线Web视频部署实验。不能通过改标题或将相机重命名为Web流构成贡献。质量与效率门槛通过后仍需真实、可审查的应用证据。

补充：新有界模型若不修复错误，必须区分学习机制失败与合法动作范围限制。已在新预测开发结果之前预注册全联合区间诊断。GT辅助区间见证只说明任意边分数扰动的可能性，不是可部署策略或学习式性能；不会据其改分数上限、阈值、候选或训练终点。
