# PIRGA 审稿问题：最终证据与限制

本轮有限预注册实验全部完成，结论为 **NO_PREDICTION_SPECIFIC_GAIN**，不具备科学成功或论文就绪证据。所有结果均是已暴露TRAIN12上的SAME_STATE_NATIVE_REPLAY_ONLY；没有新完整在线指标。

1. **为什么C1已有效还需要预测？** 当前没有成立的理由。新预测七模型1/3/5轮的7个修复与C1集合相同。原完整证据C3第5轮退化到1修复/2已认证反改错/2正确→UNKNOWN/5原UNKNOWN→错误。不能以弱C2对照掩盖C1。
2. **为什么不是普通MLP或Attention？** 已有同容量普通映射/对比目标，以及38,204参数普通成对MLP及margin版本，对照38,225参数预测模型。共同域预算、种子、顺序一致，实际激活参数/结构差异公开。第5轮D1为7修复/1反改错/3原UNKNOWN错误，D2为8/1/4，A4为7/1/4，没有预测独立优势。Attention未被实验否定。
3. **为什么必须跨摄像头？** 未建立必要性。去显式相机、去时间、同相机目标均未损失C1外新增修复，因为新模型没有这种新增修复。同相机目标原UNKNOWN错误为0是局部安全现象，且其有效预测目标覆盖111,011与跨相机73,715不同；不能据此声称跨视角机制成立或完全无用。
4. **不确定性真的有效吗？** 方差不是常数，但第5轮误差—方差相关约-0.154、与已认证匹配错误相关约0.045，均为单场景描述。1/3/5同权重门控最大方差约0.316/0.630/0.454，均低于起作用的1；三轮分数逐位相同、动作改变0。NLL改变均值与推理门控作用分开，不称身份概率，不按DEV改门槛。
5. **可靠性是否只是时间衰减？** 六个固定规则已完整重放。最近1条多修复1个，但多1个原UNKNOWN错误；其余均值、中位数、截尾均值、最近4条、固定衰减没有足够额外净收益。学习式权重网络和预测组合按Phase2失败门槛未运行，不能称它们无效。
6. **决策损失是否改善最终身份？** 已完成共同域及纯净正例补充域的全部1/3/5。共同域D2第5轮比D1多1修复同时多1原UNKNOWN错误，只有人物组5；补充域D1/D2均8修复，D2仍多1原UNKNOWN错误。没有稳健净收益或在线证据。全联合竞争输入是固定其他C1行下的代理，实际输出仍由完整Hungarian决定，非全学习矩阵求导或闭环传播。
7. **是否只处理漏接？** 是，所有实际修复仍来自漏关联，原6个错误接受均未修复或改拒绝。新有界模型对其中3个没有纯净正候选，另3个被原始状态区间证书排除。排除仅限正确身份复用及当前状态，不等于更早在线干预或拒绝-only训练不可能。训练margin监督113,453条纯净正例域；51个无纯净正确候选的原始错误进入统计而非伪造正例，未另注册拒绝-only目标，不宣称其效用已被验证。
8. **是否仅靠更多训练数据？** 主要共同域113,415/轮，完整5轮；旧Top8/latest4另有106,800/轮固定1/3/5，以及同保守掩码的原300步日程重训。全3,000旧输入/正例一致，19个训练资格查询的负例认证更保守，原300日程访问2条；S0/S1全部开发动作相同，旧结果和严格等价失败均保留。旧接口C3第5轮有一个C1外局部修复但失去4个C1修复、风险更多，净收益未建立。覆盖/顺序/资格/证据范围及执行数值差异披露，不声称纯数量因果结论。
9. **跨场景/人物/种子稳定吗？** 训练11场景，主要域139个场景—人物组，旧接口137组；开发仅已暴露TRAIN12、单种子。按人物/物理相机输出，重复候选、相同人物的连续错误和同一事件跨epoch不视为独立成功。24场景OOF、第二种子、独立验证未运行，不声称显著性或泛化。
10. **WWW贡献在哪里？** 没有新的Web实体检索、身份索引或Web视频部署实验，不具备已建立的WWW贡献。不得靠改标题、把相机改称Web流或虚构流量填补。
