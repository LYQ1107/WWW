# Phase 1：完整训练第 1 轮真实结果

11 场景的 154,911 条原生查询已全部完成输入审计。本轮共同有效训练域为 113,415 查询，包含 113,197 个排序监督查询和 73,715 个跨视角预测查询（两者有交集）；218 条只适用预测监督的访问对 C2 排序损失为零。三个模型第 1 轮都无放回完整覆盖，缺失/重复为 0。

冻结 TRAIN12 全范围 14,557 查询，含 12,259 个具有认证纯净正候选的查询。原始 GMT 存在 26 个已认证主关联错误，23 个有合法纯净正候选可达。评价保留完整原生矩阵与严格阈值，所有动作先于 GT 语义读取完成。C0、C1 每条输出与旧的同范围控制逐项一致。

第 1 轮结论为 **NO_PREDICTION_SPECIFIC_GAIN**。继承的旧辅助程序可能将 C3 对 C2/C4 的差异标记为 OFFLINE_DEVELOPMENT_POSITIVE；该旧标签已原样保留，并由新增 PIRGA 裁定明确限定：它不满足超越 C1 的门槛，不能用于准入在线。

全部结果仅为 **SAME_STATE_NATIVE_REPLAY_ONLY**，Bank/Gallery/新生 ID 的反事实传播未运行。HOTA、AssA、CVIDF1、FPS 等在线指标均未测。第 3、5 轮按原日程继续，不挑选第 1 轮，也不因负结果取消已预注册的新预测机制对照。

资源纠正：一个 CPU 影子预检曾未限定 torch.random.fork_rng 的设备范围，可能初始化 CUDA 随机状态。虽然未执行 GPU 模型训练，缺少当时逐设备进程轨迹，因此按全部 10 张卡各 64 秒保守登记上界 0.177778 GPU-hour。代码已改为 devices=[]，后续 CPU 命令设置 CUDA_VISIBLE_DEVICES 为空。正式训练的 GPU 驻留上限下调到 1.32 小时，提前完成精确断点后在 CPU 续训全部剩余更新，最坏累计父账本用量仍低于原有 4 小时上限。原 1.4 小时分配和旧账本保留，纠正由独立控制器记录，不改训练源码、数据、优化器或端点。
