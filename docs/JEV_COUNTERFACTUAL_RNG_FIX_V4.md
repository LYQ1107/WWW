## v4 implementation

- `TrajectoryRandom` preserves Python `random.sample`/`random.choices` output
  while making the RNG explicit and recording a mapping digest.
- Formal adapter calls restore a fresh RNG from `state.trajectory_rng_state`
  and fail closed if the state is absent; formal replay never falls back to
  process-global RNG.
- Each video starts from `master_seed + video_id`, with master seed `20261006`.
- `MutableGMTState.clone()` deep-copies RNG state, seed, and call count.
- `propose()` is observational. A committed `step()` advances the branch RNG
  exactly once for the initial transformer proposal.
- `resolve_actions()` and `step()` accept a precomputed proposal. REASSOCIATE
  reuses the exact score tensor and runs only constrained Hungarian after
  banning the rejected edge; it makes zero additional transformer calls.
- The runtime pilot passes one proposal through feature extraction, resolution,
  and commit.
