A current detection has no certified predecessor. Ambiguous hypotheses remain available. Twenty candidate features expose support, gap, run, appearance, displacement, coherence, uncertainty, other-camera support, dispersion, breaks, competing detections and a previously predicted purity posterior when available. They contain no annotation or future observation.
