# Phase XV Persistent Identity Architecture — version 1

Date: 2026-10-10 Asia/Shanghai. This is an implemented research candidate, not a tracking success claim. Historical GMT/Phase XIV files are unchanged.

CommitmentMemory extends the exact cached committed-history memory. It stores, for each opaque Global ID and camera, the latest real committed visual vector and normalized box, previous geometry, time, consecutive run, gaps, appearance coherence and mean. It shares records across camera payloads, retains stale IDs through native recycling, advances empty payload time, and deep-copies its versioned state. The unchanged native prefix mechanism restores both memories. IDs index records and never become learned numeric embeddings.

A current detection has no certified predecessor. Motion extrapolation and visual similarity assign soft probabilities to past observations from the same camera within eight frames, including an unmatched hypothesis. The frozen observation encoder uses 8×cosine − 20×mean normalized box distance − 0.2×gap, with unmatched logit 4. These define evidence, not a forced KEEP action. Ambiguous hypotheses remain available. Twenty candidate features expose support, gap, run, appearance, displacement, coherence, uncertainty, other-camera support, dispersion, breaks, competing detections and a previously predicted purity posterior when available. They contain no annotation or future observation.

Q4 dynamically reads those candidate-specific support tokens, past appearance, WHO scores, availability and trust alongside the current visual detection. A separate option reader gives each legal concrete ID and the native DEFER terminal an adjustable commitment value. It can change the ordering of two pure fragments. Fixed and Set controls receive all the same observed option evidence. CandidateReliability separates history purity, current selection safety and uncertainty. Pure history is not sufficient to select the person; a mixed history is not automatically a certified wrong person.

The native Hungarian solver, candidate eligibility, per-camera uniqueness, stale bank recovery, Gallery append and allocation remain the existing executor. DEFER may lead to native REACTIVATE or START_NEW; it is not a guaranteed abstention without state mutation. Fragment consolidation and aliasing are disabled. No history or previously emitted ID is rewritten.

TRAIN certificates keep all reliably pure compatible identities positive for WHO. Concrete continuation is supervised only when the actual previous ID is pure, legal and supported by a causal predecessor probability above 0.5. Necessary correction requires a confident observed predecessor certified as a different person plus clean current alternatives; a mixed predecessor alone remains UNKNOWN. Commitment loss excludes uncertified options from negative supervision while all lawful options remain available at inference. Whole-payload assignment loss uses the same constrained solver with UNKNOWN alternatives admissible.

Version 1 structural tests passed for state snapshots, restore, stale recycling, cross-camera sharing, candidate permutation and candidate-specific values. Complete TRAIN native parity and data qualification are pending. No optimizer update has yet been run. The research gates and loss weights remain the frozen preregistration.
